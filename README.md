## Filters

This plugin have exactly 1 filter.

### Paper Noise filter

- **Volume**: How loud the paper noise is.
- **Roughness**: How rough the paper surface is. Higher roughness leads to more "crispy" noise (or in technical terms,
  noise with higher frequency).
